TypeScript Vite React play client for Corvin. The application scaffold mounts a blank `/play` shell that imports CSS tokens from `@corvin-chess/design-system`. Planned surfaces: board play via [chess-core](https://github.com/corvin-chess/chess-core) WASM, lobby and clocks against [server](https://github.com/corvin-chess/server), locales from [translations](https://github.com/corvin-chess/translations), and analysis via [engine](https://github.com/corvin-chess/engine) WASM. No third-party engines, piece sets, or trackers.

```bash
git clone https://github.com/corvin-chess/web
cd web
npm install
npm run dev
```

Open the printed local URL and go to `/play`. Static build:

```bash
npm run build
npm run preview
```

`src/App.tsx` routes `/play` to `src/play/PlayPage.tsx`. Global styles in `src/styles.css` import `@corvin-chess/design-system/tokens.css`. The design-system dependency is pinned to a GitHub commit until `@corvin-chess` npm publish exists. Local play against a Compose stack from [infra](https://github.com/corvin-chess/infra) remains Planned until the real web image replaces the interim stub.
